# Politique de confidentialité — AquApp

*Dernière mise à jour : 13 septembre 2026*

## Résumé

**AquApp ne collecte, ne stocke et ne partage aucune donnée personnelle.** Toutes vos données restent sur votre appareil.

---

## 1. Données stockées sur votre appareil

Les données suivantes sont stockées **uniquement sur votre iPhone/iPad**, dans une base de données locale (SwiftData) et dans le Trousseau iOS (Keychain) :

- **Profil physique** : poids, taille, sexe (utilisés pour calculer votre objectif d'hydratation)
- **Prénom** (optionnel, pour personnaliser l'interface)
- **Historique de consommation** : volumes d'eau et d'alcool avec horodatage
- **Statistiques personnelles** : streaks, succès, défis, XP
- **Préférences** : objectif quotidien, thème, icône d'app, badge équipé
- **Photo de profil** (optionnelle, stockée dans le dossier Application Support)
- **Statut Premium** et totaux cumulés (dans le Trousseau sécurisé iOS)

### Durée de conservation
- Les données sont conservées indéfiniment sur votre appareil
- Les utilisateurs non-Premium bénéficient d'une purge automatique des données de plus de 30 jours

---

## 2. Données partagées avec Apple

### Apple Health (HealthKit) — Optionnel
Si vous activez l'intégration Santé, AquApp peut **écrire** les volumes d'eau bus dans l'app Santé d'Apple. Aucune donnée n'est lue depuis Santé. Vous pouvez révoquer cette autorisation à tout moment dans *Réglages > Santé*.

### StoreKit (achats in-app)
Les achats Premium sont gérés par l'App Store d'Apple. Nous ne stockons aucune information de paiement — seul le statut d'abonnement est vérifié localement.

---

## 3. Données que nous ne collectons PAS

❌ Aucune adresse email ou compte utilisateur  
❌ Aucun analytics, tracking ou publicité  
❌ Aucun serveur distant ou base de données cloud (sauf iCloud optionnel pour la synchronisation)  
❌ Aucune donnée de géolocalisation  
❌ Aucun identifiant publicitaire  

---

## 4. Synchronisation iCloud (optionnelle)

Si vous activez la synchronisation iCloud, vos données sont synchronisées entre vos appareils Apple via le service iCloud d'Apple. Cette synchronisation est chiffrée de bout en bout et gérée par Apple selon leur [politique de confidentialité](https://www.apple.com/legal/privacy/).

---

## 5. Widgets et extensions

Les widgets d'écran d'accueil et les Activités en direct (Dynamic Island) lisent uniquement les données locales via un App Group partagé. Aucune donnée ne quitte votre appareil.

---

## 6. Vos droits

Conformément au RGPD et aux réglementations internationales sur la protection des données :

- **Accès** : toutes vos données sont visibles dans l'app
- **Suppression** : désinstallez l'app pour supprimer toutes vos données
- **Portabilité** : utilisez la fonction d'export dans l'app (Wrapped partageable)
